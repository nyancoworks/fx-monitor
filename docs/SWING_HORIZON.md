# スイング大局と仕掛け計画の分離

スイングはH4の方向構造を監視し、M15は押し戻り後の仕掛け条件と価格余地を確認する。毎時の報告更新は想定保有期間ではない。

v8のスイング保存評価は、既存の価格計画・評価に加えて`swing_context`を持つ。

| 判断 | 基準 | 扱い |
| --- | --- | --- |
| 大局の方向構造 | 品質と確定時計を確認したH4の高値安値構造・終値 | H4確定ごとに再評価。M15だけでは撤回しない |
| H4構造無効化 | H4確定終値がH4構造無効化水準を越境 | 構造の再形成待ち |
| 仕掛け計画 | M15反応・H4の目標/無効化までの余地 | M15で越境・目標到達なら計画停止。大局の継続とは別 |
| H4のもみ合い背景 | 既存のスイング環境判定 | 監視対象外を維持 |

大局の方向が残っていても、止まった仕掛けを再開したり候補に昇格させたりしない。既存skip/grade/価格水準は変えない。価格計画の`expiry.status=withdrawn`は維持し、新版ではscopeを`保存された価格計画`に限定する。報告と前回比較では「仕掛け計画停止」と「H4構造の撤回」を区別する。

目標は保存H4終値の先にある最も近い確定ピボット（構造上の障害）。数日先の到達予測ではない。目標・無効化を遠くへ動かしたり、最低値幅や最低保有日数を追加してスイングらしく見せたりしない。

保有期間・時間決済は未定義。H4/M15という時間足だけから数日保有に適した計画であると保証しない。注文・ポジション管理・利益の評価は行わない。

デイトレH1/M5と旧保存評価の解釈は維持する。旧exportに新しい大局状態を付け足して復元しない。v8は本変更後の新しいスイング評価にだけ適用する。追加取得・頻度変更・別ジョブ・研究機能は追加しない。
