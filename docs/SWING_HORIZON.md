# スイング大局と仕掛け計画の分離

スイングはH4の方向構造を監視し、M15は押し戻り後の仕掛け条件と価格余地を確認する。毎時の報告更新は想定保有期間ではない。

v8は大局と仕掛け計画の保存・表示だけを分離した。v9では判定も変更し、H4の波の価格反応が確認できない限り、M15条件を観測してもスイングA・優先候補にしない。

数日程度にまたがるH4の波を監視する位置づけであり、毎時の報告やM15条件の更新を想定保有期間とは扱わない。実際の到達時間・保有日数は予測しない。

| 判断 | 基準 | 扱い |
| --- | --- | --- |
| 大局の方向構造 | 品質と確定時計を確認したH4の高値安値構造・終値 | H4確定ごとに再評価。M15だけでは撤回しない |
| H4構造無効化 | H4確定終値がH4構造無効化水準を越境 | 構造の再形成待ち |
| 仕掛け計画 | M15反応・H4の目標/無効化までの余地 | M15で越境・目標到達なら計画停止。大局の継続とは別 |
| H4のもみ合い背景 | 既存のスイング環境判定 | 監視対象外を維持 |

大局の方向が残っていても、止まった仕掛けを再開したり候補に昇格させたりしない。既存skip・価格水準は維持する。価格計画の`expiry.status=withdrawn`も維持し、scopeを`保存された価格計画`に限定する。報告と前回比較では「仕掛け計画停止」と「H4構造の撤回」を区別する。

## v9のH4確認

品質確認済み・同じ評価時刻の連続したH4確定足4本を保存する。最後の足は価格計画の基準足と時刻・終値が一致していなければ使わない。未確定・古い足、欠損、異なる基準足、品質不明は確認済みにしない。

次のいずれかの価格反応をH4で確認する。

- 方向への実体を伴う終値が、それ以前の3本の高値（買い）/安値（売り）を突破。
- 直前3本に逆行方向の実体があり、最後の足が直前2本の安値（買い）/高値（売り）を試し、方向への実体とその水準の内側への終値復帰を確認。

これは同じ価格反応の代替パターンであり、全指標一致条件ではない。MACD・RCI・SB等の支持/逆行は文脈として保持する。

H4の反応未確認なら、方向監視のBは残すが`practical_review.status=swing_wave_wait`として優先掲載から外す。H4の反応確認後も、M15の成立・価格余地・既存の懸念を満たさなければAにはならない。H4未確認とM15未確認を混同せず、H4が確認されれば無条件に仕掛ける処理も追加しない。

目標は保存H4終値の先にある最も近い確定ピボット（構造上の障害）。数日先の到達予測ではない。目標・無効化を遠くへ動かしたり、最低値幅や最低保有日数を追加してスイングらしく見せたりしない。

保有期間・時間決済は未定義。H4/M15という時間足だけから数日保有に適した計画であると保証しない。注文・ポジション管理・利益の評価は行わない。

デイトレH1/M5と旧保存評価の解釈は維持する。旧exportに新しい大局・波の状態を付け足して復元しない。v9は本変更後の新しいスイング評価にだけ適用する。追加取得・頻度変更・別ジョブ・研究機能は追加しない。価格反応規則の実装であり、長期有効性の実証ではない。
