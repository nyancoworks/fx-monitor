# スイングの予測に対応するH4親波

新規v12スイングの`forecast_wave_version=1`だけに適用する。方向予測は既存のSB・DMA・MACD経過・RCI等による判断を維持し、波を選ぶ前に決める。親波を遠く選ぶことで方向やA/B/Cを救済しない。デイトレH1/M5と旧保存の復元解釈は変更しない。

## 直近の小波と背景の波を区別する

以前の価格計画は、直近2件ずつに制限された2左/2右確定ピボットから最後の局所的な起点・終点を参照していた。方向を予測するだけでは、狙う波がその見通しに合うとは限らない。

新方式は既存の出所・連続性を確認したH4確定足を使用する。表示用100本への切詰め前の履歴を使い、最大500本の高値・安値・終値と先頭時刻・品質・評価時刻を限定保存する。期間不足・欠損・未来足・基準足との時計/価格不一致を補完しない。追加取得は行わない。

1. 既存DMA25×5の描画値の傾きを全観測区間で計算する。係数・シフトは変更しない。3本の傾きが同方向または横ばいで、少なくとも1本がその方向なら背景区間として記録する。一足の変化や横ばいだけでは区間を切り替えない。
2. 予測方向に対応する最も新しい背景区間を参照する。現在の背景が逆行していても、その一致を売買の必須条件にせず、直前の対応区間と現在の競合を明示する。
3. その区間に先立つ反対背景区間の開始から方向背景の開始までの確定ピボットで、買いなら最安の安値、売りなら最高の高値を親波起点とする。起点の後に確認できた方向側ピボットの最も進んだ価格を終点とする。移動平均は価格に遅れるため、終点がDMA転換後に生じることを必須にしない。
4. 内側で新しい小波ができても、親波の起点や終点をその小波へ縮めない。選択に現在の仕掛け価格・RR・最小pips・候補数を用いない。

これはFX Monitorの背景区間に基づく親波の定義であり、DMA単独の方向予測、原典再現、最適化済みの波動モデルではない。3本は短い変化と持続を区別する観測窓で、最適期間の実証ではない。背景区間開始が保有履歴の外なら、観測範囲内の参考起点であることを懸念に残す。必要な区間・起点・終点が確認できなければ、局所波に戻して目標を作らず、具体的理由とともに価格計画を保留する。

## 価格経路と撤回

- 親波の起点：大局撤回。起点の確認後にH4確定終値が越境していれば、その時刻と終値を保持し、後の反発で同じ波を復活させない。
- 親波の終点：再試しの目標。到達保証ではない。
- 直近の反対側ピボット：局所セットアップ無効化。大局撤回や口座の固定SLへ流用しない。
- 方向側の最寄り確定ピボット：途中の障害。全保有H4の確定ピボットから参照し、親波目標までの距離とは別に余地を確認する。
- 終点突破後：既存の基準足終値保持・方向側の勢い継続を確認して初めて、通常Fib拡張を有効化する。

確認足M15が先に親波終点を通過し、H4では突破が未確認の場合は、その状態を価格計画再評価の理由として表示する。古い基準足の目標を延長して追わない。MACD減速・背景競合など既存の反対根拠はそのまま評価に反映する。

親波が大きくても途中障害までの余地不足は受け入れる。H4を使うことや広い目標だけで、数日保有の有効性・到達時間・利益を証明したとは扱わない。A/B/Cはシナリオ評価であり売買許可ではない。

## 保存と確認範囲

`forecast_wave_inputs`に有限窓入力、`wave_price_plan.wave_selection`に背景区間・選定理由・履歴限界・過去撤回を保存する。復元時に同じ入力で親波と全水準を再計算する。元の価格・判断・過去の波を上書きしない。新規比較では波の選定結果を扱い、巨大な入力履歴を比較へ複写しない。

ローカル検証・本番反映・自然保存・報告への反映は別に確認し、最新状況は管理Issueに記録する。予測精度や利益改善は未実証。
