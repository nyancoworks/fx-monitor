# 保存判断の表示

新しい報告exportは `presentation_version=2` を保存する。指標係数、方向、A/B/C、候補選択、条件、水準、原本、履歴の評価を変更しない。

同ペアの方向競合は `pair_context_version=4` で、保存された `preferred_strategy` に従って両側を主監視・対案または比較経路と表示する。主監視が未設定なら両方が比較経路になる。版1〜3は従来の説明を復元する。

標準テクニカルの候補欄は、戦略・方向・評価・現在の確認状態に続けて、確認足の条件、局所停止、大局撤回、途中障害・経路目標を表示する。局所停止中や経路終了の記録を、条件観測だけで成立扱いにしない。局所停止の確認足と大局撤回の基準足を区別する。根拠・反対材料・Fib参考域・条件付き拡張・足形補足も保持する。

経済指標は保存済みの全関連イベントから通貨別に、古い出典、出典取得の劣化・失敗・停止、日時未確定の件数を先に示す。非掲載分も含み、同じイベントが複数の注意に該当し得る。該当情報の最新日程・実績を裏付けられないこと、部分入力を予定なしと扱えないことを明示する。取得成功から出典の鮮度を推定せず、欠損値や通貨方向を補完しない。元出典・権利表示・数値creditは従来どおり保持する。

版のない旧exportは表示版1として元本文を完全復元する。保存評価への表示項目の追記や原本の書換えは行わない。表示版は展開した評価の再描画との一致も検証し、未知の版を拒否する。既存タスクの権限・指示文・schedule・API上限は変更しない。

実装・ローカル検証・main反映・自然報告での反映確認は、管理Issue #1と非公開運用記録で分けて管理する。
