# スパンモデル：追加テクニカルの役割

既存v12の新規評価に`span_model_version=1`を追加する。16ペア×H4/M15・H1/M5を維持し、検証済み確定足だけを使う。取得量・頻度・API・既存指標係数は変更しない。版のない旧v12とv11以前は保存当時の解釈・本文で復元し、スパンを後付けしない。

## 計算・位置・入力

当足を含む最高値・最安値の中点を`mid(n)`とする。青色は`(mid(9)+mid(26))/2`、赤色は`mid(52)`。雲は両者の間で、計算時点に置き、未来へ先行表示しない。

遅行は終値を26区間前に置き、その位置のローソク足高安・その位置で計算した雲と別々に比較する。過去終値だけや現在の雲との比較に置換しない。26はインデックス差26（現在0なら-26）と明示し、当足を1として26本目と数える差25の実装と混在させない。外部チャート一致の認証ではない。

直近3点を観測するため、過去雲52本＋遅行26区間＋2点の80本が必要。80本の連続高安と直近3終値・先頭時刻・品質/評価時刻を限定保存する。有限窓の計算であり、MACD等の再帰初期値は変更しない。将来足・欠損・未確認の出所を補完しない。復元時に計算結果・時間足・鮮度・同世代基準足/確認足の終値と時計を照合する。不足時はスパン未確認とし、既存主要判断と区別する。

## 判断への接続

SB・DMAによる方向仮説を土台とし、スパン単独で方向を変更しない。赤色の傾き、雲に対する終値3点、遅行の過去足/過去雲との位置を分ける。同じ価格由来の根拠を独立票にしない。

- 基準足が雲の中なら押し戻り中、方向側へ抜けた初足なら回復持続未確認として、直進継続の説明を回復待ちへ修正する。既に逆行拡大・転換競合なら、その慎重な主経路を雲の回復で上書きしない。
- 基準足で2本続けて雲の反対側、または赤色の持続的な傾きが方向仮説と逆なら、背景との競合としてC・technical_recheckへ反映する。方向反転確定や波の大局撤回とは扱わない。
- 方向側で2本続く終値は継続を検討する背景で、単独でAへ昇格させない。2本/3点はFX Monitorの説明用観測窓で、原典の最適な売買規則や実証済み閾値ではない。
- 確認足で2本続けて雲の反対側なら、従来technical_watchとなる場合だけentry_recheckへ反映する。基準足方向・波の目標/撤回・局所無効化水準は変更しない。雲の交差単独を新しい売買条件にせず、全指標一致も必須にしない。

予測の`support/cautions/primary_path`と`span_model.base/trigger`に説明を保存する。既存レポートで根拠・懸念・確認足の状態を読めるため、定期タスクの長文化は不要。レンジ逆張り・自動売買・時間決済は追加しない。

## 参照と限界

- [開発者の3スパンの役割](https://real-int.jp/articles/1652)：赤色の傾き、青色と価格、遅行と過去足/ゾーンを区別する。
- [開発者の基本解説](https://real-int.jp/articles/873)：9/26/52を参照。ただし青色の説明には高安和をそのまま2で割る表記があり、一定価格で青色が価格の2倍になる。本実装は2つの期間中点の平均と明示し、一定価格・独立した極値計算で検証する。
- [JFX講演資料](https://www.jfx.co.jp/category/webseminar/pdf/v_equationsp.pdf)：SBとスパンの役割・時間足を組み合わせる考え方を参照。原典の全売買手法の再現ではない。
- [開発者の遅行スパン資料](https://www.span-model.com/chikouspan/soubahandan_ppt.pdf)：26遅行と21遅行を区別。インデックス規約は上記に固定する。
