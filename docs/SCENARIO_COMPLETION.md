# A/B/Cと確認足の反応

新規M15/M5シナリオに `scenario_completion_version=1` を保存する。

従来は、確認条件が定義済みなら、反応がまだ観測されていない `waiting` でもA評価になる経路があった。Aが「具体的なシナリオが成立」、Bが「方向は有望だが確認待ち」という定義と食い違う。

新規版は、既存のA要件を満たしていても確認足の反応が未観測ならBとし、理由に反応待ちを明記する。一つの代替反応が観測されれば、この不足は解消する。全指標一致、指標票数、固定RR閾値は追加しない。重要な反対根拠がある場合は、反応だけでAへ昇格させない。

方向・目標・無効化・価格計画・反応検出方法は変更しない。Aは約定、売買許可、利益保証ではない。旧保存は版なしの従来判定で復元し、原本を書き換えない。

これは評価定義と実装の不一致の修正であり、マーフィー流の原典にA/B/C分類があるという主張ではない。SB・スパンの局面別解釈、他のテクニカルを含む予測精度の検証は別工程。
