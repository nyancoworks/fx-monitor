# テクニカル見通しと波の価格計画（v10/v11）

新規v12スイングの波の選定は[予測に対応するH4親波](FORECAST_PARENT_WAVE.md)を参照。直近小波と親波を区別し、旧保存には後付けしない。

## 新規v12の価格経路確認

`price_path_review_version=1`の新規評価では、既存の波・起点・終点・途中障害を維持したまま、終点再試しと拡張目標の有効化を区別する。基準足終値が終点未到達なら`retest`。到達後は、基準足終値2本が終点の方向側で保持され、既存の3点MACD経過が方向側で改善または維持しているときだけ`extension_active`とする。それ以外は`extension_wait`で、参考Fib拡張域は保存するが`scenario_target`を未設定にし、拡張までの仮想RRで優先候補を救済しない。確認済み起点の撤回・最遠拡張域到達は`withdrawn`。

2本保持は突破初足と保持を区別する当システムの観測定義であり、最適化した利益基準・到達保証ではない。全指標一致は求めず、再帰初期値や係数は変更しない。終点到達後の確認待ちは価格計画の再評価であり、波の起点による大局撤回や方向反転とは別。確認足が基準足より先に終点へ到達しても、古い基準足の終点を延ばして救済しない。

版のない旧v12・v11以前は保存時の目標選択と元本文で復元する。新しい経路段階は`wave_price_plan.path_stage`に保存する。狙う波そのものを選び直す変更や、障害重要度の新しい分類は含めない。

新規生成の方向予測は[v12](TECHNICAL_FORECAST.md)。以下のv10/v11の方向解釈は旧保存の復元用で、波の水準の役割・通常Fib・最寄り障害までの余地の扱いはv12でも維持する。

v11世代では両戦略に以下を適用した。価格計画はv10から維持し、勢いの経過の判断だけを次節で追加した。旧v10の保存評価・本文へ新しい経過を付け足さない。

## v11：押し戻りの進行と回復の経過

既存の品質確認済みH4/H1確定足から、同じ指標計算・係数・初期値を用いて直近3本の観測を作る。MACDとPreferred Stochasticは元の全検証済み履歴の各時点までのprefixで計算し、直近3本からEMAを初期化し直さない。RCI9/26/52は各時点の既存の有限窓計算、DMAは既存3x3の描画値を使う。新規API取得・頻度増加・指標パラメータ変更はない。

- MACDが方向と逆でも、2区間で逆行が強まる場合と鈍る場合を区別する。強まる場合は方向のBを保持しつつ`technical_recheck`として優先監視を保留。鈍化は再開確定ではなく、BをAへ引き上げない。
- MACDが方向側でも2区間で減速していれば、直進継続ではなく押し戻りへの移行を主経路にする。変化が混在する場合や中立は再加速を断定しない。
- Aの完成度を維持するには、既存の条件に加え、方向側の勢いが改善または安定し、DMA方向側の位置が少なくとも直近2本で保持されていることを確認する。一足だけのMACD反転・DMA回復では完成度を上げない。RCIとストキャスを含む全指標一致や票数にはしない。
- RCI26/52の持続性の回復・悪化・混在は、MACDの勢い・DMAの位置と別の役割の情報として保持する。逆行だけで売買方向を反転させたり、転換確定としたりしない。

`technical_outlook.evolution`に時刻・状態・短い根拠を保存し、主経路・懸念・評価・優先状態へ反映する。元の3点を限定保存し、復元時は同じ基準足終値・時刻、同世代の既存MACD/DMA/ストキャス/RCIの最新値との一致も確認する。古い足・将来足・欠損・別足・値不一致は経過未確認とし、推測で補完せずA・優先掲載を保留する。基準足の方向監視と経過評価の保留は区別する。

この3本は運用上の観測窓であり、最適化された利益モデル・保有期間・転換予測精度の実証ではない。波のアンカー選択、通常Fibの比率、最寄り障害を含む価格余地条件は変更しない。経過の改善を理由に遠い目標へ変えたり候補を増やしたりしない。

新規の全32評価に適用する。スイングH4/M15、デイトレH1/M5、レンジ逆張り廃止は維持する。指標の期間・係数・DMA描画シフトは変更しない。特定トレーダーの完全再現、勝率モデル、到達時間モデルではなく、既存の観測に対するFX Monitor独自の裁量判断の明文化である。

## 判断の順序

1. 品質確認済み基準足の方向構造を土台に、SB中心線・遅行・σ位置・帯幅を環境として解釈する。反対側なら移行局面、方向側への帯拡大なら継続、それ以外の方向背景では押し戻り後の継続を条件付き主シナリオとする。スイングの既存もみ合い除外は維持する。
2. 基準足MACDの逆行は、継続直進ではなく押し戻りを先に想定する根拠。RCI26/52は持続性の懸念、RCI9とPreferred Stochasticは短期の回復を説明する。DMA3x3の価格位置で押し戻り中と回復局面を区別する。SMA、DMA7x5/25x5、上位足、通貨強弱の根拠も同世代で保持する。多数決・総合点・全指標同時一致の方式にはしない。
3. 同じH4/H1の確認済み波に対して、通常Fibの38.2～61.8%を押し戻り参考域、既存波の終点を再試し目標、終点突破・勢い継続後の1.272～1.618を条件付き拡張域とする。既存計算の比率を用い、独自の教師手法として表示しない。反転・到達保証ではなく、終点突破前に拡張を確定目標として追わない。
4. M15/M5の反応は局所の仕掛けを確認する補足。直近数本のPAだけでは大局を作らず、特定のH4 PAパターンも大局判断の必須条件にしない。

## 水準の役割

| 項目 | 根拠と扱い |
| --- | --- |
| 大局撤回 | 確認済み基準足の波の起点を、同基準足の確定終値が越境。近い局所高安や確認足だけで大局を撤回しない |
| 局所セットアップ無効化 | 直近の基準足反対側ピボット。確認足の越境なら仕掛け停止。大局撤回・固定SLではない |
| 途中の障害 | 進行方向の最も近い確定ピボット。到達候補と分けて必ず余地を確認 |
| 経路目標 | 波の終点再試し。その先は終点突破・勢い維持を条件とした通常Fib拡張域 |

`wave_price_plan`に根拠アンカー・役割別水準を保存し、`reference_levels.structural_target`は構造障害の意味を維持する。投影を構造支持抵抗へ改称しない。別の`scenario_target`は条件付き経路目標を表す。

## 評価と掲載

`technical_outlook`が方向シナリオ、`wave_price_plan`が価格経路、`scenario_conditions`が局所仕掛け。Aは基準足の継続・回復局面と波の価格余地を説明できる状態で、局所条件観測済みや売買許可を意味しない。押し戻り中・懸念ありはBとして監視できる。局所PAの成功だけでAにせず、未観測だけで基準足の見通しを否定しない。

優先掲載の`technical_watch`は、鮮度確認済み確認足から、経路目標まで・最初の構造障害までの余地が、波の起点までの距離をともに上回る費用前の監視計画。遠い投影の高RRだけでは近い障害を無視できない。従来の幾何学的な余地条件であり最適化したRR・最低pips・最低日数ではない。条件水準での仮想RRに戻って掲載を救済しない。

局所無効化は`entry_recheck`、基準足背景競合は`technical_recheck`、余地不足は`price_plan_recheck`、重要発表をまたぐ場合は`event_recheck`。これらで候補欄を埋めない。主要品質・テクニカル環境・確認済み波が不足なら`evaluation_pending`、明確な方向なし・もみ合い除外・大局撤回・拡張終点到達は`skip`。波の起点が遠い場合も目標を延ばしてRRを作らず余地不足を受け入れる。

数セッションのH4の波／日中のH1の波という対象を区別するが、到達時間・保有日数・時間決済は推定しない。口座・費用・約定・保有ポジションは取得しない。成績の検証・研究自動化は追加しない。

## 保存・互換性

`contextual_scenario_review_v10_technical_wave`を両戦略の新規生成に適用。既存市場取得の足と観測だけを利用する。波入力の直近基準足・確認済みアンカー・高安一覧と、既存の直近5本の仕掛け入力を限定保存し、復元時は見通し・水準・評価・条件・掲載状態を再計算して照合する。取得量・頻度・報告時刻・ジョブ数は増やさない。

旧v7～v9の復元・本文は変更しない。旧評価に新しい見通しを付加しない。通常の前回条件比較では、局所仕掛け停止・経路目標到達・基準足による大局撤回を区別する。凍結した価格・条件を今回の新シナリオで上書きしない。
