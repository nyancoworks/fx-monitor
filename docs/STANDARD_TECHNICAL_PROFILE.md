# 標準テクニカル構成（現行）

ユーザー合意により、新規生成をv13に変更する。16ペア×スイングH4/M15・デイトレH1/M5の32評価を維持し、スイング主軸・デイトレ補助とする。

使用する指標はスーパーボリンジャー（既存21本・遅行21本）、通常MACD（短期EMA12・長期EMA26・シグナルEMA9）、通常フィボナッチ、SMA50/200、RCI9/26/52のみ。価格構造を価格計画に使う。新規判断ではPAパターンを方向・評価・仕掛けの独立条件に使わない。通常BB単独戦略・レンジ逆張りは追加しない。

MACDの各EMAは保有する検証済み連続足の先頭から、最初の期間分のSMAを初期値として再帰計算する。シグナルは有効なMACD列の最初の9値のSMAからEMA9を開始する。MT4等のシグナルSMAや他の再帰初期値との完全一致は主張しない。短い直近窓だけで初期化し直さない。RCIは既存の同値平均順位の計算を使用する。SMA200などの不足は未確認として開示し、補助指標不足だけで全評価を止めない。

SBの方向・遅行・帯幅を環境として使うが、SB方向を常に優先しない。SMA50の位置・傾きと方向側MACDの改善がSB背景に対立する場合は転換仮説を保持し、C・再評価待ちとして転換完了と区別する。MACD確定3足の方向側改善/減速・逆行拡大/鈍化/混在を区別する。SMA50/200の位置と傾きは中長期背景、RCI26/52は持続性・転換、RCI9は短期反応を読む。張り付きは自動逆張り理由にしない。同一価格由来の根拠を多数決や独立票にしない。W1/D1は確認できる保存背景だけを補助に使い、欠損/未検証を補完しない。

波はDMAやSMAの区間へ機械的に置換せず、基準足の左右2本で確認された価格ピボットから選ぶ。保有範囲内で最も早い未撤回起点と、その後の方向側の確定極値を用い、RR最大化・近い高安の最終目標化を行わない。保有範囲外の真の起点や保有日数は推定しない。局所停止と起点による大局撤回、途中障害、波の終点、通常Fibの条件付き1.272/1.618拡張を分ける。終点の外側で基準足終値2本を保持しMACDが方向側で改善するまでは拡張を有効化しない。投影到達時に目標をさらに延ばさない。確認足で通過済みの高安は前方障害から外し、既存の確定高安から次の障害を読む。

A/B/Cはシナリオ完成度。構造・勢い・価格計画を役割別に確認し、重要な反対材料を反映する。局所条件観測は約定・売買推奨ではない。方向仮説と仕掛け条件、データ不足と相場による見送りを区別する。相反する時間軸は保存版3の統合判断で主監視/対案/未解決を読む。固定的なH4優先や一律逆方向除外を行わない。

新規の指標準備/判断/出力から、ディナポリ係数MACD・DMA・Preferred Stochastic・スパンモデル・SMA100の依存を撤去する。旧モジュールと旧仕様文書は、v12以前の評価・元本文の完全復元とその回帰確認のために保持し、新規生成では呼ばない。原本・履歴は削除/改変しない。市場API・頻度・保存世代・通知を変更しない。実装/試験/本番/自然採用と、予測精度や収益性の実証は区別する。

v13保存レコード版2は、確認足終値による局所セットアップ停止を明示し、大局撤回が未到達でも仕掛けを再評価待ちにする。レコード版1は当時の判断・元本文の復元互換を維持する。版の違いは指標係数の違いではない。

新規の仕掛けタイミングは確認足のRCI9で読む（買いは直前/現足で−80以下に達した後の上向き、売りは＋80以上から下向き）。極端域への到達だけでは成立としない。指標反応の観測は方向予測・A評価・約定ではなく、方向背景、価格計画、局所停止も保持する。買いのRCI9反転時だけ下ヒゲ/強い陽線を補足観測するが、無くても候補や評価を下げない。参考分類は下ヒゲが実体/上ヒゲより長い、または陽線実体が直前4本の実体中央値とヒゲ合計を上回ること。確立した原典や優位性の実証ではなく、100点・利益保証とは扱わない。旧PA条件の読み取りは保存本文復元用に残す。
