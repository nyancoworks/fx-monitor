# 保存シナリオの前向き確認

`diagnostics.scenario_quality_review.review_saved_followup` は、保存レポートと
次の保存済みfollowupをオフラインで照合する読取り専用関数です。取得・定時処理には
組み込まず、API、Actions、通知、収集頻度を増やしません。返す実データは非公開で
保管し、公開ログ・Issue・テスト例へ転記しません。

呼出し側は同じimmutable private commitからレポート・source・元snapshot blobを
確認し、次世代followupも固定します。関数はレポートを完全復元し、前世代の32評価が
履歴と一致すること、全reviewについて保存済みM5足から後続観測を再計算して一致する
ことを検証します。別世代、重複、観測改変は拒否します。保存足の出所ラベルやGitの
一致は、別の市場データ源による独立検証ではありません。

条件観測済みの例だけを成功例として抜き出さず、全reviewを先に照合します。
条件待ち・観測済み・比較不能を保存当時のまま区別します。欠落・未確認出所・目標なし
は観測可能件数と分け、欠けた期間を補完しません。観測開始は保存評価時刻であり、
通知到達や実際の取引開始時刻ではありません。ヒゲによる水準接触は、確定足での
シナリオ撤回や約定を意味しません。異なる長さの期間を混ぜて勝率・収益率を計算せず、
スイングを短い観測期間だけで最終評価しません。

`complete_saved_m5_window` は、評価時刻より後に始まり次の評価までに終了する
完全なM5足の並びに欠落がない、という意味です。評価時刻をまたぐ途中の足を含めた
全時間の観測とは限りません。`saved_m5_coverage` に評価間の秒数、対象となる完全足の
秒数、境界で対象外となる秒数、実際の観測足の秒数を区別して返します。欠損・出所不明
は別途完全性を失い、対象足を観測できない場合の観測秒数はnullです。全評価時間を
欠落なく含む場合だけ `continuous_saved_evaluation_window` がtrueになります。
いずれも通知から通知までの観測や、約定から決済までの観測を意味しません。

同じペア・戦略の次世代保存評価も別欄で示します。過去の条件観測済みを現在へ
持ち越さず、条件待ちへの再評価、見送り、保存された撤回を区別します。次世代では
比較水準や方向が変わる場合があり、同じポジションや継続中の同一シナリオとは
みなしません。過去の評価は書き換えません。

掲載の確認では、既存の保存時既定候補と同条件の比較相手を返します。同条件の相手が
なければ、価格余地で順位が改善したと扱いません。これは定時タスクによる最終選択や
異なる局面間の総合順位が最適だったとの証明ではありません。反対根拠の数、RR、
後から見えた値動きで評価や方向を変更しません。掲載ロジックの見直しが必要な場合は、
研究結果と提案を分け、合意後に変更します。
