# スーパーボリンジャーとスパンモデルスペシャルによる判断

[Issue #124](https://github.com/nyancoworks/fx-monitor/issues/124) に対応する新規評価の保存方式は `murphy_sb_span_v1` です。

| 戦略 | 背景 | 主軸 | タイミング |
| --- | --- | --- | --- |
| スイング | W1 / D1 | H4 | H1 / M15 |
| デイトレード | D1 / H4 | H1 | M15 / M5 |

主軸でSBの方向側トレンドと青色スパンの位置から方向を読みます。主軸の確定足や指標が不足する場合は評価保留、方向が得られない場合は見送りです。上位足の逆行はCとして記録し、主軸の方向を維持します。方向側のタイミングと同方向の上位足があればA、それ以外の方向候補はBです。2本のタイミング足のうち、どちらかで方向側を確認します。

| 項目 | 買いの目安 | 売りの目安 |
| --- | --- | --- |
| エントリー基準 | 主軸SB中心線と青色スパンの高い方 | 主軸SB中心線と青色スパンの低い方 |
| 損切り | 主軸SB −1σ、青色スパン、赤色スパンの最安値 | 主軸SB ＋1σ、青色スパン、赤色スパンの最高値 |
| 利確目安 | 主軸SB ＋3σ | 主軸SB −3σ |

カードの価格は保存時の確定足終値を参照し、取得できる最も短い対象足を時刻付きで表示します。条件が観測済みならその価格、待機中はエントリー基準からpipsと費用前RRを表示します。価格が損切り水準または利確目安に到達済みの計画、および水準が構成できない計画はTOP3の対象外です。損切りは価格到達を基準とし、実際の現在値は取引画面で確認します。

MACD（EMA12・26、EMA9シグナル）とRCI9/26/52は表示用です。確定波、高安更新、ATR、RSI、ADX、DMA、Fib、SMA単独、ディナポリMACD、Preferred Stochastic、レンジ逆張りは新しい判断経路に入りません。

TOP3はシナリオ評価と仕掛け状態を優先し、同じ段階では既存H1通貨強弱の方向との関係・変化から得た優先度とRRを比較します。カードの数値は従来の対象ペア除外モデルから取得します。ゲージ中央はゼロ、両端はそのカードの両通貨のうち絶対値の大きい値です。変化矢印は同じ通貨ペア集合で比較できる同じ長さの前期間との差です。定時報告の全体ランキングは既存の24時間強弱を表示します。

ファンダメンタルズは取得済み政策資料と経済指標を使います。資料の政策決定、予定の時刻・JST、情報の鮮度、重要指標の急変動リスクを示します。通貨の強弱見通しとテクニカル方向との関係は判定根拠が保存されていなければ不明です。比較可能な単一の公表金利が両方にある場合、適用日付きで参考差を示します。時間分析は主軸のスパン信号からの経過と、スイングの日足観測を補助表示します。どちらも方向・評価・候補選定に影響しません。

保存は16ペア×2戦略、既存の保存形式・参照元照合・3世代履歴を使用します。過去の保存結果は元の方式で復元します。収集・API・定時タスクの設定は従来どおりです。
