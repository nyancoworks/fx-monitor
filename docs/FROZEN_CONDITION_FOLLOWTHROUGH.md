# 前回条件を保存間の足で確認する

`data/scenario-continuity.json`の隣接する全32評価比較に、任意の
`previous_condition_followthrough`を追加する。前回の条件・方向・目標・無効化を固定し、
今回snapshotの既存保存足で、その間の価格反応を確認する。
毎回再計算される局所水準との比較とは別で、候補・評価・方向・順位は変えない。

保存処理は前後のreport/source/snapshot blobを従来どおり照合する。
新情報には今回snapshotの元バイトを渡し、Git blob hashも照合する。
同じprivate commit/pushへ保存し、追加の取得・Actions・スケジュールを増やさない。
元バイト未提供の旧呼出しは従来の比較を維持する。
任意情報が未検証でも、主要な保存評価を候補なしへ変更しない。

## 観測の意味

- 前回が条件待ちの場合だけ、新しい条件観測として記録する。
  既に観測済み、撤回済み、条件未定義、候補外、評価保留も全32行に状態を残す。
- 前回の押し戻り反応・終値突破・突破後の別足での再試しをそのまま検査する。
  再試し失敗後に別の水準を作って成功扱いにしない。
- 確認足は出所ラベルが既存のTwelve Dataである完全なM5を使う。
  スイングM15はUTCで整列した3本を必要とする。
  基準足H1/H4の終値は本番同様に保存H1から確認し、M5終値で代用しない。
- 最初の反応終値で元の目標・無効化に対する距離と参考比を計算する。
  既存の費用前「目標距離が無効化距離を上回る」判定を表示し、新しい閾値は導入しない。
  約定価格・成立後の利益・費用控除後の期待値ではない。
- 確認足と基準足の終値による元水準への到達、M5内の水準接触を区別する。
  後で撤回条件が観測されても、それ以前の反応記録は消さない。

## 確認限界

評価時刻をまたぐ途中足は、前回判断の後だけの完全な足として使えない。
最初と最後の除外秒数、完全な確認足数、欠損・出所未確認、基準足の被覆を保存する。
欠損区間を補間せず、条件不成立へ読み替えない。基準足の被覆不足では、観測できた
局所反応を現在も有効なシナリオとは断定しない。

同方向でも旧水準の継続有効性は証明されない。後の再評価を前回へ上書きせず、
今回の候補判断と固定条件の観測を分ける。通知の到達時刻・その後の約定・
売買成績は測定しない。反復する保存判断を独立した取引標本として合算しない。
