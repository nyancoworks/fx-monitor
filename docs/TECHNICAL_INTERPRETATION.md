# テクニカルを相場の解釈と監視へ使う

新規v12の`technical_interpretation_version=1`に適用する。方向や値幅を作り直す変更ではない。旧版なしv12以前の保存判断・元本文は、そのままの意味で復元する。

## 見直した点

従来の優先掲載は、目標と最寄り障害までの距離が、ともに波の起点への大局撤回距離を上回ることを要求していた。これは大局の幾何学的な比率であり、未確定の仕掛け価格・実際の損失幅・費用込みのRRではない。親波を広くした場合にもこの比率を一律の掲載条件にすると、方向と待つ反応を説明できるB評価を監視から消してしまう。

新しい監視掲載では、この大小比較を必須にしない。元の距離と比率は参考として保存し、余地の弱さを隠さず、実際の仕掛けRRが未確定と明記する。局所高安を勝手に損切り幅へ置き換えない。比率だけで有望としたり、目標・撤回を動かしたりもしない。

## 各テクニカルの使い方

- SBの方向環境と遅いDMAの価格位置が予測方向を支え、価格構造が明確な反対方向でなければ、短期逆行を直ちに転換確定とは扱わない。指標の全一致や票数を求めない。
- MACDの方向側減速は調整を先に想定し、逆行鈍化は押し戻り減速の材料とする。変化混在・中立でも背景が保たれていれば、背景維持の回復待ちとして説明する。
- MACD逆行拡大中は方向のB仮説を保持できるが、再開を先取りせず優先掲載を保留する。構造や遅いDMA価格位置が方向と競合する場合は、既存の弱い予測・C評価を維持する。
- RCI9の逆行は背景内の押し戻りの進行として読む。RCI26/52の方向側極端域は持続の参考で、極端域だけで逆張りしない。既存の傾き・転換・張り付き情報を用い、独立票には数えない。
- Preferred Stochasticの反応は、DMA位置とMACD経過に照らして回復・逆行を読む。短期反応だけで大局を反転させない。
- スパンの雲越境・赤色の傾きだけで、残るSB/DMA背景を上書きしてCにしない。逆行の懸念は保存し、背景内の調整・回復待ちとして読む。確認足の雲越境だけを仕掛け停止条件にしない。
- PAは保存足で具体的な反応を確認する材料。特定パターンを追加の必須条件にしない。

これは役割を永久固定する原典再現や最適化された予測モデルではない。既存の計算係数・再帰初期値・観測窓を変更しない。

## 引き続き保留する場面

主要な品質・鮮度・方向・有効な波の不足、波の撤回、基準足背景と構造の重要な競合、逆行拡大、局所セットアップ無効化、条件の具体化不能、再試し失敗、発表をまたぐ場合の既存扱いは維持する。目標または最初の障害が既に保存確認足価格の後方なら、古い目標を使って追わせない。拡張目標は従来の確認後だけ有効化する。

`technical_watch`は、方向と具体的な待つ条件を継続監視する意味であり、現価格で有効な取引・成立後RR・注文可能性を認定しない。候補数を埋めるためにCや条件未確認を掲載しない。Aは今回の固定距離条件撤廃によって増やさず、従前の完成度・懸念・参考余地を満たす場合に限る。

報告は主経路・重要な反対材料・待つ反応・大局撤回・目標を保存判断から示す。指標一覧や内部手順を利用者本文へ追加しない。新しいステータスや売買許可は追加しない。

同評価・同じ確認状況の新規候補は、旧来のPAパターン優先リストで並べ替えない。根拠の異なる候補をRRだけで上下させず、比較条件が同じ場合だけ既存の参考余地比較を使う。それ以外の同条件の並びは保存32評価の順序を保ち、根拠のない総合順位を作らない。並びの変更は `technical_order_version=1` の新規保存に限定する。解釈版だけを持つPR #59を含め、旧保存の並びと元本文は維持する。

## 検証の限界

同一保存入力で、方向・目標・撤回・波を維持して解釈と監視掲載への影響を確認する。候補が増えること自体は改善の証拠ではない。完全復元・本番反映・自然採用と、実際の予測精度・費用込みの有効性は別に扱う。実例・検証結果・残る確認は管理Issueと非公開記録に保存する。
