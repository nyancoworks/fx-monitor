# テクニカル方向予測 v12

新規生成の両戦略は `contextual_scenario_review_v12_technical_forecast` を使用する。
高安構造の方向を先に固定せず、既存の品質確認済み基準足の指標から方向仮説を作る。
スイングH4/M15、デイトレH1/M5、16ペア×2戦略は維持する。

## 見通しと反対経路

SB中心線・遅行・σ位置・帯幅を環境仮説として使い、DMA25x5の背景位置・傾き、DMA3x3の回復持続、MACDの複数足の経過から、継続・押し戻り拡大/鈍化・調整移行・回復待ち・転換途中を区別する。
SB中心線が横ばいでも、遅いDMA背景と検証済み方向側の勢いから暫定仮説を作れる場合がある。
SBと遅いDMA背景が逆で逆行MACDが拡大する局面では、DMA背景方向の転換仮説も扱う。SBと競合する以上、確定方向やAとはせずC・再評価待ちとする。

RCI26/52の傾きと複数足の持続性は予測の弱点に反映する。RCI9・Preferred Stochasticの位置、転換、クロス、張り付きは短期反応として保存し、逆行なら仕掛け回復待ちを説明する。単独で方向を反転させない。DMA7x5、SMA100/200、上位足、通貨強弱の既存観測も保持し、重複した独立票にしない。

これは役割に応じた明示的なFX Monitor独自の仮説分岐であり、指標票数・固定総合点・全指標同時一致ではない。常に正しい予測、最適化モデル、特定トレーダーの原典再現、利益率や保有期間の実証ではない。

## 構造とPA

価格構造が仮説と逆なら重要な未解決の反対材料としてCにできるが、方向を構造側へ戻さない。構造未確定でも、同方向の確認済み波・撤回・目標があれば計画を評価する。確認済み波がなければ価格計画は評価保留とし、旧方向の水準や遠い投影で救済しない。

方向選択後に、その方向で既存の通常Fib、確認済みピボット、目標・撤回、通貨強弱/上位足の関係、M15/M5条件を再生成する。波の選択方式・Fib比率・最寄り障害までの価格余地は今回変更しない。
ローソク足PAは仕掛け確認であり、基準足の方向仮説を作る入口ではない。PA観測だけで矛盾を消したりAに昇格しない。

## 評価、保存、互換性

`technical_outlook.forecast` に方向、局面、主経路、反対経路、支持/懸念、短期反応、検証済み経過を保存する。重要な環境競合・逆行拡大・経過未確認などは弱い仮説としてCに反映し、優先候補にしない。有望だが調整/回復待ちはB。継続局面で重要な懸念がなく価格余地も確認できる場合に限りAとする。勝率や売買許可ではない。

復元時は同じ限定保存入力から予測方向・見通し・価格計画・評価・条件・優先状態を再計算する。方向と入力が不整合なら拒否する。
旧v11以前の保存は元の処理で復元し、新しい予測を後付けしない。前回の固定条件は今回の再予測と分けて追跡する。

新規保存の`contextual_review_version=1`では、確認足の構造/テクニカル逆行、通貨強弱に対する価格側の根拠、実体/ヒゲの記述量を`judgment_review`で説明する。移行局面では一足の局所押し戻りで突破後の再試しを省略しない。マーカーなしの旧v12は当時の解釈・本文で復元する。詳細と将来足の確認範囲は[判断監査](TECHNICAL_JUDGMENT_AUDIT.md)を参照。

市場/経済指標API、収集回数、Actionsジョブ、指標係数・初期値は追加変更しない。レンジ逆張り・メール・終了研究は再開しない。
