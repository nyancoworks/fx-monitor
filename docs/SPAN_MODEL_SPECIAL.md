# スパンモデルスペシャル（現行）

名称：スパンモデルスペシャルは、スーパーボリンジャーとスパンモデルの組み合わせ。別の第三の指標ではない。モジュール名・保存キーの `span_special` は互換性のため保持する。

## 確認足の組み合わせ（murphy_timing_context_version=1）

M15/M5でもSB局面・動きの方向、青色と価格、赤色の傾き、遅行と過去足/雲、観測できる変化時間帯を同じ確定足から計算する。従来は確認足の青色回復だけがタイミング処理へ渡り、これらの背景が条件の根拠に欠けていた。新規評価は `scenario_conditions.evidence.murphy_context` に全観測と方向に反する要素を保持し、確認足の説明へ組み込む。

RCI/MACD等の局所反応を観測したことと、シナリオ全体が成立したことを区別する。材料は固定票数・多数決・一律ANDゲートへ変換しない。今回、方向・A/B/C・既存の局所反応条件を変更しない。版のない保存記録は当時のまま再現する。

開発者の役割説明（https://real-int.jp/articles/873 、https://real-int.jp/articles/414）と、本人の遅行スパン資料（https://www.span-model.com/chikouspan/soubahandan_ppt.pdf）を参照。一般的な役割の照合と、ソフトウェアの表示規約・売買成績の検証は別である。原典の裁量判断を完全に機械化できたとは扱わない。

計算監査：青色・赤色の非定値系列の数値、遅行比較位置、買い/売りの対称性、過去雲不足を合成OHLCで確認。インデックス差26は従来どおりであり、外部製品と同一の数え方かは未確定。原典の記事内に青色中点化の省略と読める式があるため、本文下段の計算規約と未確認事項は引き続き有効。推測で1本ずらさない。オートシグナル製品の再現や収益向上を主張しない。

新規32評価に `span_special_version=1` を保存する。SB21/21、MACD12/26/9 EMA9、RCI9/26/52、SMA50/200、通常Fib、既存価格計画と併用する。H4背景・H1セットアップを分析し、M15/M5の青色スパン回復を既存のRCI/MACD/SBと並ぶタイミング候補に加える。全指標一致を要求しない。上位W1/D1は従来SBの環境認識を維持する。

## 原典確認と計算

- 開発者 https://real-int.jp/articles/873 : 青色と価格、赤色の傾き、遅行と過去足/ゾーンを分ける。雲の色はサイン方向そのものではない。交差発生時に価格が雲より上なら売りサイン、下なら買いサイン。雲内は方向未判定。信号とサイン同方向を順行、逆を逆行として記録。
- 同記事の変化時間帯の目安を採用：H1以上5本、M15 7本、M5 8本。点灯足を1本目と数える実装上の規約。売買シナリオの失効期限ではない。将来の転換時刻を予言しない。
- 開発者 https://real-int.jp/articles/414 : SBとの併用がスペシャル。価格方向・勢いと時間分析を総合する。

青色=(9本高安中点+26本高安中点)/2、赤色=52本高安中点。記事873の青色の式は中点化が省略されたように読めるため、旧計算と同様に期間中点の平均を採用し、一定価格で同価格になることを検証する。雲は現在位置。遅行はインデックス差26で過去足高安/過去雲と比較。SB遅行21とは別。外部製品の表示規約一致は未確認。

既存の検証済み確定OHLCを使用し追加取得なし。53本で現在/前足の雲、78本から当該遅行位置の雲を計算できる。不足項目は未確認とし、スパン全項目不足だけで全候補を保留にしない。週末やNYクローズの連続性は既存frame検証を引き継ぐ。未来足を使わない。

## 判断への接続（FX Monitorによる実装解釈）

雲だけでCにする旧処理は復活させない。青色の反対側への価格推移とMACD逆行拡大/混在が重なる場合、継続仮説を弱めて再評価する。変化時間帯の反対サインは転換リスクとして反映するが、サイン単独で売買方向を反転しない。赤色・遅行の背景は支持/懸念へ明記。新しい独立票には数えない。

青色の方向側へ確定終値が回復した観測をタイミング候補へ追加。既存の他の代替条件、価格計画、局所停止は維持する。後続足も当初保存の条件と同じ計算で観測する。復元時に保持OHLCから再計算する。版のない旧保存は当時のまま。過去原本・評価を書き換えない。

表示は既存の根拠/懸念と待ち条件に組み込み、別の長いレポートを増やさない。オートシグナル製品の完全再現、原典の全裁量判断の再現、予測精度/収益改善の実証は未対応。原典確認、実装の計算テスト、本番自然実行、実際の有効性は別々に確認する。実装の検証結果・本番採用は非公開運用Issueで管理する。

## 確定足間の変化（span_transition_version=1）

原典873の青色と価格、赤色の向き、遅行と過去足・雲の役割に沿い、現在位置に加えて直前確定足との差を根拠へ表示する。青色・遅行の上/下/絡み、赤色の上向き/下向き/横ばいへの変化を分離する。横ばい化を逆方向への転換と断定しない。変化は当該確定足の事実であり、将来予測や単独の売買サインにしない。

前の比較対象が不足している場合は変化を作らない（過去雲の比較は現在分だけでなく前足分も必要）。スパン同士を独立票として加点せず、既存の支持/懸念の文中へ統合する。判定方向、評価、タイミング条件は変更しない。旧版にこの観測項目や文章を追加せず、旧保存の復元を維持する。計算式とインデックス差26の表示規約、猶予期間の数え方には上記の未確認・実装解釈が残る。原典完全再現や精度改善の実証は未完了。

## 赤色スパンの新たな高安更新（span_red_turn_version=1）

新規判断では、赤色スパンの52本高安中点の数値変化と、52本の高値・安値を新しく更新したかを分ける。過去の極値が計算窓から抜けただけで赤線が上下しても、赤色の方向転換とは記載せず「方向更新なし」とする。新しい高値と赤線の上昇、新しい安値と赤線の下落がそろった確定足だけ、方向更新として支持・懸念に使う。両側更新など数値方向が合わない場合は更新方向を断定しない。値の差分自体は観測結果に保持し、線が完全に横ばいだったとは主張しない。

開発者の[赤色スパン解説](https://real-int.jp/articles/895)は、52本高値・安値の更新を赤色の向きの変化として扱う。これはその記述に合わせた FX Monitor の実装解釈で、外部製品のオートシグナル完全再現ではない。H4/H1と確認足M15/M5の赤色背景へ同じ解釈を使う。方向・評価・価格計画を単独で反転するゲートは追加しない。旧保存には版を後付けせず、従来の数値傾きの表示・評価を再現する。予測精度は前向きの実結果で別途確認する。


## 定時掲載用の短い保存データ

`data/task-report.json` は同じ収集で作成する非公開の表示用データ。既存report_textの優先順から両戦略最大3件を抜き出し、条件・価格・根拠・懸念を保存する。指標計算、評価、順位は変更しない。source・snapshot blob・対象枠を同梱し、強弱や前回照合の欠落で確認済み候補を止めない。前回の確定足目標到達と同一目標が確認できたスイング候補だけ、従来合意どおり個別に計画待ちへ表示する。元履歴・完全なレポートは保持。補助ファイル生成失敗は当該ファイルをunavailableにし、原本保存を妨げない。定時タスクは短い完成本文を優先して転記し、再選定・独自順位付けをしない。
