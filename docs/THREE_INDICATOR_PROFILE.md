# 新規判断の3指標版（three_indicator_version=1）

> 旧保存の参照資料です。Issue #124以降の新規判断と定時表示は[現行仕様](MURPHY_PROFILE.md)を参照してください。

- 主軸：スーパーボリンジャー（局面・方向・確認足反応）とスパンモデル（青・赤・遅行の位置と変化）。両者を独立票として数えない。
- 補助：通常MACD 12/26/9（EMA9シグナル）で勢い・交差・逆行を読む。局所反応だけで全体成立や売買許可とはしない。
- 確認済み高値・安値は価格経路の材料であり第4の指標ではない。手前の節目、局所停止、波の再試し目標、大局撤回を分ける。目標通過後は新しい価格計画待ち。
- 新規判断の方向・A/B/C・タイミング・TOP3にSMA50/200、RCI9/26/52、通常Fibを使わない。旧保存の再計算は版番号なしの旧経路で維持する。保存足には旧計算値が残る場合があるが、新規の根拠には採用しない。
- 固定票数、指標の全一致、一律の値幅ゲートは設けない。判断の有効性、TOP3の実用性、スイングの追跡期間は既存保存履歴で別途検証する。
- この選択を変更する場合は利用者の明示的な方針変更、新しい版番号、保存履歴との比較を要する。過去の結果を書き換えない。
- [時間・価格の公開規則ベース観測](ACTIVATE_TIME.md)は別の参考文脈。3指標の同格票には加えず、方向・A/B/C・TOP3に未接続。
