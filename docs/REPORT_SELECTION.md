# 保存シナリオの掲載順位

`strategy_report.report_records()` は、32評価のうち `review` を戦略ごとに最大3件掲載する読取り専用処理です。A/B/C、方向、成立条件、全32評価、保存原本は変更しません。非掲載の検討候補も見送りにはしません。

selection_version=2ではまずA/B/Cを優先し、同評価の中では具体的な待つ条件を示せる候補を先に並べます。条件待ち・突破待ち・再試し待ち・保存足での条件観測済みをこの対象とし、観測済みを他の待ち状態より自動優先はしません。条件を組めない・再試し失敗・確認状況不明の候補は、評価を維持したまま同評価内の後側に置きます。売買方向やA/B/Cの変更、候補の削除、売買許可の追加はありません。

この表示上の区分内は既存候補順を維持し、以下の比較条件が一致する候補間だけで、保存終値から構造目標までの距離を無効化までの距離で割った参考値を比較します。

- 同じ評価・戦略・トレンド／レンジの種類・局面。
- 同じ条件確認ルートと確認段階、参考パターンの確認状態。
- 同じ反対根拠・未確認事項、通貨強弱の関係と変化。
- 同じ価格の基準（基準足だけの候補と、後の確認足まで検証できる候補は別）。

比較条件が異なる候補の掲載枠は維持します。高いRRだけで、反応未確認・押し戻り中・逆行背景の異なる候補を他の比較条件の枠へ繰り上げません。反対根拠の数を点数化せず、未知の注意事項はそのまま比較条件に残します。既存評価が生成した参考RR／距離の注意文だけは、比較対象そのものなので、価格から再現できる既知の文面に限り比較条件から除きます。文面が変わった場合は保守的に別の比較条件となります。

計算には保存された構造目標・無効化・終値だけを使います。基準足価格のRR整合性と確定時刻を照合し、後の確認足保存終値が検証できればそちらを使います。確認足を観測済みと記録しながら時刻・価格・RRが不整合な場合は、基準足への差替えによる順位上昇をしません。構造目標がない場合もFib参考投影で補完しません。比較できない候補と同値の候補は従来の順序を維持します。

レポートには価格の基準と参考距離比、目標までの距離が無効化までの距離より小さい場合の説明を付記します。固定RRによる除外・評価変更はなく、現在の売買価格、成立後RR、約定、勝率や利益を示す値ではありません。

この比較は限定的な表示改善です。異なる局面間の総合順位や手法の優位性を検証したものではありません。テストは合成シナリオと32評価・JSON・圧縮履歴・日本語レポートの経路で行い、本番の自然出力と到達確認は別工程です。API取得・Actions起動・実行頻度は増やしません。

「比較条件が異なる候補の掲載枠は維持」は同じ表示区分内の価格余地比較に適用します。条件の再評価が必要な候補が掲載枠に残る場合も、確認状況と保存された理由を明示し、通常の条件待ちと混同しません。この並び順は定時タスクが全根拠を文脈で比較する際の既定例であり、最適な総合順位を保証しません。

保存exportにはselection_version=2を記録し、復元時はその版で本文・比較本文・順番を検証します。版のない旧exportはselection_version=1として、従来の掲載順と当時の本文のまま復元します。未知の版・版と本文の不一致は拒否します。旧評価viewを使う診断も保存された版を参照し、現在の並び順を過去の掲載結果として扱いません。

新しい保存exportは `comparison_explanation_version=2` を別途記録し、掲載本文・全候補比較本文の各候補に、同条件の比較相手がいるかを表示します。相手の件数は非掲載を含む全検討候補から数えます。比較相手なし・比較情報不足・比較相手ありを区別し、参考値が計算できるだけで順位改善済みとは説明しません。比較条件や掲載順、評価・方向・全32評価は変更しません。版のない旧本文は説明版1のまま厳密に復元し、未対応の版や本文との不一致は拒否します。定時タスクの指示・出力形式は変更せず、比較用全文をそのまま通知へ追加しません。
