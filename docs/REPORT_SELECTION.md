# 保存シナリオの掲載順位

`strategy_report.report_records()` は、32評価のうち `review` を戦略ごとに最大3件掲載する読取り専用処理です。A/B/C、方向、成立条件、全32評価、保存原本は変更しません。非掲載の検討候補も見送りにはしません。

まずA/B/Cと既存候補順で並べます。そのうち、以下の比較条件が一致する候補間だけで、保存終値から構造目標までの距離を無効化までの距離で割った参考値を比較します。

- 同じ評価・戦略・トレンド／レンジの種類・局面。
- 同じ条件確認ルートと確認段階、参考パターンの確認状態。
- 同じ反対根拠・未確認事項、通貨強弱の関係と変化。
- 同じ価格の基準（基準足だけの候補と、後の確認足まで検証できる候補は別）。

比較条件が異なる候補の掲載枠は維持します。高いRRだけで、反応未確認・押し戻り中・逆行背景の異なる候補を他の比較条件の枠へ繰り上げません。反対根拠の数を点数化せず、未知の注意事項はそのまま比較条件に残します。既存評価が生成した参考RR／距離の注意文だけは、比較対象そのものなので、価格から再現できる既知の文面に限り比較条件から除きます。文面が変わった場合は保守的に別の比較条件となります。

計算には保存された構造目標・無効化・終値だけを使います。基準足価格のRR整合性と確定時刻を照合し、後の確認足保存終値が検証できればそちらを使います。確認足を観測済みと記録しながら時刻・価格・RRが不整合な場合は、基準足への差替えによる順位上昇をしません。構造目標がない場合もFib参考投影で補完しません。比較できない候補と同値の候補は従来の順序を維持します。

レポートには価格の基準と参考距離比、目標までの距離が無効化までの距離より小さい場合の説明を付記します。固定RRによる除外・評価変更はなく、現在の売買価格、成立後RR、約定、勝率や利益を示す値ではありません。

この比較は限定的な表示改善です。異なる局面間の総合順位や手法の優位性を検証したものではありません。テストは合成シナリオと32評価・JSON・圧縮履歴・日本語レポートの経路で行い、本番の自然出力と到達確認は別工程です。API取得・Actions起動・実行頻度は増やしません。
