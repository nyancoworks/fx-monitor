# 保存指標を候補の根拠・懸念・待つ局面へ反映する

最終計算にM15のDMA、M15/M5のスーパーボリンジャーとM5の帯域観測を含める。
`indicator_refresh.refresh_strategy_indicators`は、本番とテストで共有する取得なしの処理。
既存の検証済み足を使い、時間足・品質・確定時刻の確認を経た観測だけを解釈する。

## DMAの価格位置と傾き

3×3・7×5・25×5を保持する。終端をn、描画シフトをsとすると、現在の足に描かれる値は
`SMA[n-s]`であり、最新の`SMA[n]`ではない。後者は将来の描画位置へ置く既知の平均値で、
将来価格ではない。`current_plot`、`previous_plot`、`source_timestamp`を分けて保存し、
ウォームアップ不足では最新平均値で代用しない。

価格位置と傾きを売買方向に対して別々に解釈する。基準足の25×5は背景の価格位置、
確認足の3×3は短期反応の位置として説明し、3本全ての価格位置・傾きを保持する。
逆側にある価格や逆向きの傾きを、押し戻り・背景との競合として懸念へ反映する。
交差だけで新しい方向・価格目標を作らない。

## 帯・遅行・勢い

中心線と構造の整合に加え、遅行スパンが過去ローソク足の上・下・内側のどこか、
帯が拡大・縮小・横ばいか、保存終値が1σ帯のどこにあるかを分けて説明する。
単一足の帯拡大を継続的なバンドウォークと断定しない。パラメータは既存の参考設定で、
原手法や外部チャートとの完全一致を認定したものではない。

MACD・Preferred Stochastic・RCIの詳細な根拠は維持する。
`technical_context`は、時間足別の支持・懸念・未確認と短い要約を保存する。
短期の価格位置や勢いが逆行する場合、既存の価格反応条件を観測するときにDMA位置と
勢いを再評価する注意を待ち条件へ添える。指標全一致を新しい成立条件にしない。

## 境界と互換性

新規入力のみ`contextual_indicator_context_v2`を付け、派生要約
`saved_technical_context_v1`を再計算して保存検証する。古い保存評価を新解釈へ書き換えない。
具体的な価格反応条件・方向・構造目標・無効化・既存A/B/C方針は維持する。
不足・古い観測は未確認とし、最新の価格や指標値を推測しない。

新しい要約を含むexportは`payload_layout=canonical_rows_v2`で評価を一度だけ保存し、
既に一致を検証した一覧行を読出し時に完全復元する。元snapshotは変更しない。
圧縮JSONの旧形式も復元でき、900,000byteのexport上限と16MiBの復元view上限は維持する。
根拠・反対根拠・新しい指標観測は省略しない。

候補理由へ実際に反映するが、同じ価格から作る指標の多数決・独立票・一律加点や
新しい売買許可にはしない。短い定時報告では、保存要約から判断に重要な支持と懸念だけを
選び、全指標・全数値を毎回列挙しない。追加API、頻度、発注、ポジション管理は導入しない。
