# Scenario maturity versus monitoring priority

New assessments use concrete saved confirmation conditions for A/B maturity.
An old reference pattern alone is insufficient for A. Conversely a concrete,
verified reaction is not vetoed merely because any one lagging price-derived
indicator or a remote weekly context differs. All original cautions remain.
A remains unavailable with a conflicted base structure/trend regime, material
currency-strength opposition, provisional range interpretation, insufficient or
unverified current price margin, or unobserved concrete conditions. This is a
contextual scenario review, not indicator votes or proof of profitability.

Price margin uses the fresh confirmed M5/M15 close, actual structural target
and invalidation. The remaining reward must exceed the risk before costs to
support an A or priority monitoring plan. This is a geometric minimum, not an
optimized RR threshold, win-rate estimate or executable-price recommendation.
A reference RR at the older H1/H4 close cannot rescue an exhausted newer plan.
C, skip, pending, targets, directions and original stored observations remain.

The separate saved practical_review records why a scenario is waiting, has a
confirmed reaction, needs a new price plan, or needs an event reassessment.
Precisely timed relevant high-impact releases from the last analysed base close
through the next hourly reporting slot receive event-recheck priority. This is
a visibility window tied to actual data/report cadence, not a predicted market
impact duration. Uncertain, cancelled or date-only times are never invented;
missing calendar data does not imply event safety. Event context does not
change the technical grade or assert a release result/market reaction.

Selection version 3 prioritizes viable monitoring plans, retaining existing
price-context comparison within comparable groups. Price-plan/event rechecks
remain in all32 assessments and complete review text, but do not fill the
priority list. Old versions 1/2 reproduce their exact original saved listings;
old frozen grades are never recalculated during restore. Export version 3 is
explicitly accepted alongside the earlier versions, including mixed-generation
continuity. The task should state why there is nothing to prioritize rather
than treating these records as nonexistent or market rejection.

This policy is provisional. Offline frozen-view re-review is not full raw-price
replay and does not measure missed entries, fills, transaction costs or profit.
