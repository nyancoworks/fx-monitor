# 公開規則ベースの時間・価格観測（版1）

原典と同じ候補を完全再現したとは主張しない。公開解説 [時間分析と価格分析](https://real-int.jp/articles/845) の基本数値・対等時間・タイムサイクルを、検証済み保存D1/W1確定足で探索する。原典例との照合および売買成績は未確認。

- 両端を含めて足を数える。基本数値9/17/21/26/33/42/52と、各数値の約10％（四捨五入して最低1本）の範囲を候補にする。
- 高値・安値は前後2本より厳密に高い/低い確定ピボットだけを使う。右2本が閉じるまでは選ばず、同値は選ばない。最新の高値と安値を別々に数える。
- 対等時間は直近の確定高値と確定安値の間隔を、後側ピボットからの経過と比較する。周期は直近3つの同種ピボットの間隔を比較する。候補の選択はFX Monitorの限定的な実装規約で、原典の全候補・裁量選択の再現ではない。
- 前日足の高値・安値を最新日足終値で超えたかを別に示す。節目候補だけで転換・加速・売買を確定しない。スパンモデルの5/7/8本の変化時間帯とは別の観測。
- 16ペアに1つずつ保存し、各ペアD1最大120本/W1最大80本の元高安・終値を保持して再計算を検証する。新しい市場取得、収集頻度変更はない。過去の版番号なしの保存は変更しない。
- スイング報告の参考行のみ追加。方向、A/B/C、条件観測、目標、局所停止、TOP3選択に影響させない。原典との一致や経路改善が検証されるまで売買判断へ昇格しない。
