# 保存済み過去足の棚卸し

既存の後続保管が通常更新のため復号した月別bundleから、provider・pair・時間足・月ごとの
本数、最初/最後の足、M5/H1の等間隔グリッド上の欠落数と区間数、出所を集計する。
欠落を休日や市場休場と推測せず、日足の欠落はUTC経過日数から推測しない。
月をまたぐ連続性の確認・全期間の完全性・取引成績は別の検証である。

集計は元bundleのhashと結び付け、既存のindex/backupと同じ保管更新で保存する。
Release本文にも60,000byte以内なら同じ集計を添え、読取り時は復元済みindexとの一致を検査する。
それ以上のサイズでは本文への重複掲載をせず、indexに完全な集計を保持する。
全内容を読み直していない古い月はunknown_bundle_keysに残す。
古い月の追加ダウンロードはしない。元の足・初回観測・改定履歴を変更しない。

データ追加も通常の更新理由もない回は従来どおりunchangedで終了する。
棚卸しのためだけのアップロード・指示タスク・市場API・スケジュールを追加しない。
旧index/pointerはそのまま読め、次の通常更新で確認できた範囲から集計する。
独立した長期保管庫全体の復元や、損益バックテストの完了を意味しない。
